# Contributing

FoodPlanner is a personal portfolio project.

- **Issues and suggestions are welcome.** Bug reports, ideas and questions can be
  opened at <https://github.com/Catalyst4K/FoodPlanner/issues>. For security
  problems, please follow `SECURITY.md` instead of opening a public issue.
- **Pull requests are not accepted.** The code is not open-licensed (see
  [`LICENSE`](LICENSE)), so outside contributions can't be merged.

## Working agreement

Changes by the maintainer (and by agent sessions working on their behalf) follow
[`CLAUDE.md`](CLAUDE.md), which describes the architecture and the rules for
working in this repository.
